Types of distribution

The workshop looked at one histogram. This session looks at the recognisable shapes distributions come in — and checks which one ours is.

Theoretical distributions

Theoretical distributions describe idealised properties — not the frequencies in one dataset, but the likelihood of values in an abstract “population.” They’re fully described by a handful of parameters.

Source: Békés & Kézdi (2021), Data Analysis for Business, Economics, and Policy, Ch. 3

The normal distribution

  • Bell-shaped, symmetric — mean, median, and mode coincide
  • Fully described by two parameters: \(\mu\) (the mean) and \(\sigma\) (the standard deviation)
  • Examples: height, IQ, measurement error
{
  const rng = d3.randomNormal(0, 1)
  const sample = Array.from({ length: 4000 }, rng)
  return Plot.plot({
    height: 240,
    x: { label: "x", domain: [-4, 4] },
    y: { label: "% of draws", percent: true },
    marks: [
      Plot.rectY(sample, Plot.binX({ y: "proportion" },
        { x: d => d, thresholds: 30, fill: "#457b9d", fillOpacity: 0.8 })),
      Plot.ruleX([0]),
    ]
  })
}

The log-normal distribution

  • Normal arises from summing many small, independent effects. Log-normal arises from multiplying them — and since \(\log(a \times b) = \log a + \log b\), the log of such a variable is itself a sum, so it’s approximately normal
  • Transform a normal \(x\) with \(e^x\) and you get exactly this: always non-negative, long right tail
  • Examples: income, firm size, our reaction-time data — each the result of many small multiplicative factors (attention, motor noise, distraction, …)
{
  const rng = d3.randomLogNormal(0, 0.5)
  const sample = Array.from({ length: 4000 }, rng)
  const cutoff = d3.quantile(sample.slice().sort(d3.ascending), 0.99)
  return Plot.plot({
    height: 240,
    x: { label: "x", domain: [0, cutoff] },
    y: { label: "% of draws", percent: true },
    marks: [
      Plot.rectY(sample.filter(d => d <= cutoff), Plot.binX({ y: "proportion" },
        { x: d => d, thresholds: 30, fill: "#2d6a4f", fillOpacity: 0.8 })),
      Plot.ruleX([0]),
    ]
  })
}

The power-law distribution

  • Also called the Pareto distribution — large extreme values are common at any scale
  • Examples: city population, word frequency, wealth
{
  const alpha = 2.5, xmin = 1
  const sample = Array.from({ length: 4000 }, () => xmin * Math.pow(1 - Math.random(), -1 / alpha))
  const cutoff = d3.quantile(sample.slice().sort(d3.ascending), 0.97)
  return Plot.plot({
    height: 240,
    x: { label: "x", domain: [0, cutoff] },
    y: { label: "% of draws", percent: true },
    marks: [
      Plot.rectY(sample.filter(d => d <= cutoff), Plot.binX({ y: "proportion" },
        { x: d => d, thresholds: 30, fill: "#e63946", fillOpacity: 0.8 })),
      Plot.ruleX([0]),
    ]
  })
}

Other common distributions

Not covered in this chapter of the textbook, but useful to have in view:

Distribution Typical shape Common use
Uniform Flat — all values equally likely Random number generators
Bernoulli Two outcomes (0 or 1) Single test: pass/fail, yes/no
Binomial Count of successes in n trials Defects per batch, correct answers
Poisson Count of events in a fixed interval Arrivals per hour, emails per day

Our data, and its log

If reaction times are log-normal, the log of reaction time should look roughly normal. Let’s check, using the class data collected in the workshop.

{
  const rtSorted = rt.slice().sort(d3.ascending)
  const rtCut    = d3.quantile(rtSorted, 0.98)
  const logRt    = rt.map(Math.log)

  const p1 = Plot.plot({
    height: 240, width: 380,
    x: { label: "Reaction time (ms)", domain: [0, rtCut] },
    y: { label: "% of trials", percent: true },
    marks: [
      Plot.rectY(rt.filter(d => d <= rtCut), Plot.binX({ y: "proportion" },
        { x: d => d, thresholds: 20, fill: "#457b9d", fillOpacity: 0.8 })),
      Plot.ruleX([0]),
    ]
  })
  const p2 = Plot.plot({
    height: 240, width: 380,
    x: { label: "log(reaction time)" },
    y: { label: "% of trials", percent: true },
    marks: [
      Plot.rectY(logRt, Plot.binX({ y: "proportion" },
        { x: d => d, thresholds: 20, fill: "#2d6a4f", fillOpacity: 0.8 })),
      Plot.ruleX([0]),
    ]
  })

  return html`<div style="display:flex;gap:24px;justify-content:center;">${p1}${p2}</div>`
}

Raw reaction times (blue) are right-skewed with a long tail. Their log (green) looks far closer to symmetric and bell-shaped — exactly what the log-normal claim predicts.
