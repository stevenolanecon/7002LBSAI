// Screen readers walk into an SVG's own children unless told otherwise —
// Observable Plot gives every mark and axis tick its own generic aria-label
// ("dot", "x-axis tick", ...), so without this wrapper a screen reader reads
// through dozens of those instead of one meaningful description. Wrapping in
// a role="img" container and hiding the SVG itself (aria-hidden) makes the
// wrapper's one aria-label the whole story.
function accessibleChart(node, label) {
  node.setAttribute("aria-hidden", "true")
  const wrapper = document.createElement("div")
  wrapper.setAttribute("role", "img")
  wrapper.setAttribute("aria-label", label)
  wrapper.appendChild(node)
  return wrapper
}

Types of distribution

The workshop looked at one histogram. This session looks at the recognisable shapes distributions come in — and checks which one ours is.

Theoretical distributions

Theoretical distributions describe idealised properties — not the frequencies in one dataset, but the likelihood of values in an abstract “population.” They’re fully described by a handful of parameters.

Source: Békés & Kézdi (2021), Data Analysis for Business, Economics, and Policy, Ch. 3

The normal distribution

  • Bell-shaped, symmetric — mean, median, and mode coincide
  • Fully described by two parameters: \(\mu\) (the mean) and \(\sigma\) (the standard deviation)
  • Examples: height, IQ, measurement error

The log-normal distribution

  • Normal arises from summing many small, independent effects. Log-normal arises from multiplying them — and since \(\log(a \times b) = \log a + \log b\), the log of such a variable is itself a sum, so it’s approximately normal
  • Transform a normal \(x\) with \(e^x\) and you get exactly this: always non-negative, long right tail
  • Examples: income, firm size, our reaction-time data — each the result of many small multiplicative factors (attention, motor noise, distraction, …)

The power-law distribution

  • Also called the Pareto distribution — large extreme values are common at any scale
  • Examples: city population, word frequency, wealth
{
  const alpha = 1.6, xmin = 1
  const sample = Array.from({ length: 4000 }, () => xmin * Math.pow(1 - Math.random(), -1 / alpha))
  const cutoff = d3.quantile(sample.slice().sort(d3.ascending), 0.97)
  return accessibleChart(Plot.plot({
    height: 420,
    x: { label: "x", domain: [0, cutoff] },
    y: { label: "% of draws", percent: true },
    marks: [
      Plot.rectY(sample.filter(d => d <= cutoff), Plot.binX({ y: "proportion" },
        { x: d => d, thresholds: 30, fill: "#e63946", fillOpacity: 0.8 })),
    ]
  }), "This chart shows the characteristic shape of a power-law distribution, where extreme values are far more common than in a normal or log-normal distribution. 4,000 simulated draws, almost all small with a very long fat tail of much larger values.")
}

Source: Békés & Kézdi (2021), Ch. 3 — shapes simulated here to show each family’s characteristic silhouette

The uniform distribution

  • Flat — every value in a range is equally likely
  • Fully described by two parameters: the minimum and maximum
  • Mean and median sit at the midpoint, but there’s no peak — no value is any more “typical” than another
  • Examples: random number generators, rounding error, waiting time within a fixed interval
{
  const rng = d3.randomUniform(0, 10)
  const sample = Array.from({ length: 4000 }, rng)
  return accessibleChart(Plot.plot({
    height: 420,
    x: { label: "x", domain: [0, 10] },
    y: { label: "% of draws", percent: true },
    marks: [
      Plot.rectY(sample, Plot.binX({ y: "proportion" },
        { x: d => d, thresholds: 20, fill: "#f4a261", fillOpacity: 0.8 })),
    ]
  }), "This chart shows the characteristic flat shape of a uniform distribution, where every value in a range is equally likely. 4,000 simulated draws between 0 and 10, bars roughly the same height across the whole range.")
}

The Bernoulli distribution

  • The simplest distribution — a single trial with two possible outcomes
  • Think of an unfair coin: heads = success. Fully described by one parameter, \(p\) — here \(p = 0.3\), so heads comes up on average 30% of the time, tails the other 70%
  • The building block every other distribution on this page is made from
  • Examples: a single coin flip, one pass/fail test, one yes/no question
{
  const p = 0.3
  const sample = Array.from({ length: 4000 }, d3.randomBernoulli(p))
  // Bars are built with explicit x1/x2 centred on each outcome (0 or 1) rather
  // than Plot's own interval-binning, which left-aligns each bar to its value —
  // on a continuous-looking axis that reads as ambiguous which bar is which.
  const counts = d3.rollup(sample, v => v.length / sample.length, d => d)
  const rows = Array.from(counts, ([k, prop]) => ({ k, prop }))
  return accessibleChart(Plot.plot({
    height: 420,
    x: { label: "Outcome", domain: [-0.5, 1.5], ticks: [0, 1], tickFormat: d3.format("d") },
    y: { label: "% of draws", percent: true },
    marks: [
      Plot.rectY(rows, { x1: d => d.k - 0.5, x2: d => d.k + 0.5, y: d => d.prop, fill: "#1d3557", fillOpacity: 0.8 }),
    ]
  }), "This chart shows the simplest possible distribution — a single trial with two outcomes — as the building block every other distribution on this page is made from. 4,000 simulated draws with a 30% success probability: the failure bar at zero is taller, roughly 70% of draws, the success bar at one shorter, roughly 30%.")
}

The binomial distribution

  • The number of successes across \(n\) independent Bernoulli trials — the same unfair coin as before, heads = success, now flipped \(n\) times
  • Described by two parameters: \(n\) (number of trials) and \(p\) (probability of success on each) — still \(p = 0.3\) here
  • As \(n\) grows, its shape approaches the normal distribution — a preview of why the normal shows up so often
  • Examples: defective items in a batch, correct answers on a multiple-choice test

The binomial distribution — working out the probabilities

With \(n = 2\) trials and \(p = 0.3\), there are two different orders that both give exactly one success — so their probabilities get added, not counted once.

Sequence Probability Successes
Fail, fail \(0.7 \times 0.7 = 0.49\) 0
Success, fail \(0.3 \times 0.7 = 0.21\) 1
Fail, success \(0.7 \times 0.3 = 0.21\) 1
Success, success \(0.3 \times 0.3 = 0.09\) 2

\(0.21 + 0.21 = 0.42\) — exactly the “1 success” bar on the chart.

The Poisson distribution

  • The number of events in a fixed interval, given a constant average rate
  • Described by a single parameter: \(\lambda\) (lambda), the average rate itself
  • Mean and variance are both exactly \(\lambda\) — a distinctive fingerprint of this distribution
  • Examples: customer arrivals per hour, emails per day, typos per page
  • Try the slider — see what changes on the next slide

The Poisson distribution — what changes with \(\lambda\)?

Dragging \(\lambda\) on the last slide changes two things at once:

  • The whole distribution shifts right — a higher average rate means more events are expected, so the peak moves from wherever it was to wherever \(\lambda\) now sits
  • It also spreads wider — variance equals \(\lambda\) too, so a higher average rate also comes with more uncertainty around it

By around \(\lambda \approx 15\)–\(20\), the shape is already hard to tell apart from a normal distribution — the same pattern we just saw with the binomial as \(n\) grew. That’s not a coincidence: both are examples of the same general fact — many distributions start looking normal once their parameters get large enough, which is a big part of why the normal distribution shows up everywhere.

The Poisson distribution — a “thin tail”

At \(\lambda = 4\), values far from 4 don’t just get rare — they get rare fast. In a real 4,000-draw simulation, the count never once went above 13.

The true probability of seeing, say, 100 is about \(3 \times 10^{-100}\) — a decimal point, 99 zeros, then a digit. For contrast, that’s smaller than 1 in the number of atoms in the observable universe.

This is the opposite of the power-law distribution from earlier in this session: there, big outliers stayed plausible at every scale. Not every right-skewed shape behaves the same way in its tail — worth checking which kind you actually have before trusting how far a value “could” go.

Our data, and its log

If reaction times are log-normal, the log of reaction time should look roughly normal.

A handful of trials run well over a second — much slower than the rest, and enough to dominate a raw histogram on their own. We’ll set those aside for now, and work with trials under 800ms.
