// Screen readers walk into an SVG's own children unless told otherwise —
// Observable Plot gives every mark and axis tick its own generic aria-label
// ("dot", "x-axis tick", ...), so without this wrapper a screen reader reads
// through dozens of those instead of one meaningful description. Wrapping in
// a role="img" container and hiding the SVG itself (aria-hidden) makes the
// wrapper's one aria-label the whole story.
function accessibleChart(node, label) {
  node.setAttribute("aria-hidden", "true")
  const wrapper = document.createElement("div")
  wrapper.setAttribute("role", "img")
  wrapper.setAttribute("aria-label", label)
  wrapper.appendChild(node)
  return wrapper
}

How do we understand a variable?

Before any model, any test, any result — you need to know what your data actually looks like.

What is exploratory data analysis?

Exploratory data analysis (EDA) is the process of describing your variables — the values they take, how often they take them, and whether anything is unusual.

This is the crucial step to take before you do anything else with the data.

Békés & Kézdi frame it as three questions to ask before any model:

  • How should you start the analysis itself?
  • How do you describe the data and present its key features?
  • How do you explore the data and check whether it’s clean enough for further analysis?

Source: Békés & Kézdi (2021), Data Analysis for Business, Economics, and Policy, Ch. 3

Why bother with EDA?

Five reasons:

  1. To check data cleaning — EDA is part of an iterative cleaning process
  2. To guide subsequent analysis — what you see shapes what you do next
  3. To give context for interpreting later results
  4. To ask additional questions — EDA can refine the research question itself
  5. It can offer simple, but possibly important, answers on its own

Source: Békés & Kézdi (2021), Ch. 3

Visualising distributions

Frequency, probability, distribution

  • Absolute frequency — the count of observations with a particular value
  • Relative frequency — that count expressed as a proportion, or percentage, of all observations
  • Probability generalises relative frequency: a measure of the likelihood of an event, always between 0 and 1 — and, unlike relative frequency, it can describe an event without needing a dataset at all
  • The distribution of a variable tells you the frequency of each value it takes in the data, independent of what the other variables show

Source: Békés & Kézdi (2021), Ch. 3

Visualisation

  • Statistics are useful but it often (always?) useful to look at your data
  • There are many ways to understanding the distribution of your variables
  • Histograms are the most famous

What is a histogram?

A histogram is a bar chart of a variable’s distribution — bars show how many observations (or what percentage) fall in each bin.

Reading one, look for:

Feature What to look for
Modes Peaks that stand out from their neighbourhood
Centre and tails Where most of the mass sits, and how it thins out
Symmetry Symmetric, or a long left/right tail?
Extreme values Points far from the rest, out in the tails

What do we do with an outlier?

For every extreme value, ask three questions — in order:

Question If yes Reaction-time example
Is it an error? Drop or fix it A 4 ms trial — a mis-click before the screen turned green
Is it real, but not what we’re studying? Drop it, with a note A slow trial because the student was talking to a neighbour
Is it a genuine feature of the process? Keep it A slow trial from real hesitation — this is operational variability

The decision changes what you’re measuring. Dropping every slow trial doesn’t just clean the data — it can quietly redefine the metric.

Summary statistics

What is a summary statistic?

For any variable, a statistic is a meaningful number you can compute from the data. Summary statistics describe the most important features of a distribution — its centre, its spread, its shape.

Source: Békés & Kézdi (2021), Ch. 3

The mean and expected value

It is standard to refer to our variable as \(x\). The mean (or average) of \(x\) is calculated as:

\[\bar{x} = \frac{\sum x_i}{n}\] If we have \(a\) and \(b\) that are fixed whilst \(x\) varies we get two useful properties: \(\overline{x+a} = \bar{x} + a\) and \(\overline{x \cdot b} = \bar{x} \cdot b\).

The expected value, \(E[x]\), is the value you’d expect for a randomly chosen observation.

  • For a quantitative variable, \(E[x]\) is the mean
  • For a binary variable coded 0/1 — like caffeine — \(E[x]\) is the probability, or relative frequency, of the category coded 1

Source: Békés & Kézdi (2021), Ch. 3

Median, quantiles, mode

  • Median — the middle value when sorted; half the observations lie below, half above
  • Quantiles / percentiles divide the data into proportions. Quartiles divide it into fourths — the median is the 2nd quartile, the 50th percentile
  • Mode — the most frequent value; some distributions have more than one

Source: Békés & Kézdi (2021), Ch. 3

Variance and standard deviation

\[Var[x] = \frac{\sum (x_i - \bar{x})^2}{n-1} \qquad SD[x] = \sqrt{\frac{\sum (x_i - \bar{x})^2}{n-1}}\]

  • Variance is the average squared deviation from the mean — harder to interpret directly, but easy to work with algebraically because it is itself a mean
  • Standard deviation is the square root of variance — back in the original units, and roughly the typical distance between a randomly chosen observation and the mean

Note

This divides by n − 1, not n — the standard formula, and what Python uses. Békés & Kézdi’s own textbook divides by n instead; the difference is small in practice, and we’ll come back to exactly why in Week 2.

Two distributions can share a mean but differ in spread: the higher the SD, the more dispersed the data. In finance, SD is literally how volatility is measured — a higher SD means a price that jumps around more.

Source: Békés & Kézdi (2021), Ch. 3

Range = max − min. Simple but dominated by extremes.

SD = √variance. Same units as the data. Sensitive to outliers.

IQR = Q3 − Q1. Spread of the middle 50%. Robust to outliers.

90–10 range = 90th percentile − 10th percentile. A middle ground — trims the most extreme 20% without being as narrow as the IQR.

Standardised values and skewness

Standardising expresses a value in units of standard deviation:

\[x_{\text{standardised}} = \frac{x - \bar{x}}{SD[x]}\]

A standardised value of 1 means “one SD above the mean”; −1 means “one SD below.”

A distribution is skewed if it isn’t symmetric. A simple measure:

\[\text{Skewness} = \frac{\bar{x} - \text{median}(x)}{SD[x]}\]

When the right tail is long, the mean sits above the median and skewness is positive — exactly why our reaction-time data is right-skewed.

    const h = sigma * 1.06 * Math.pow(vals.length, -0.2)
    const xs = d3.range(bMin, bMax, 2)
    const dens = x => d3.mean(vals, v => {
      const u = (x - v) / h
      return Math.abs(u) <= 1 ? 0.75 * (1 - u * u) / h : 0
    })
    const maxDensity = d3.max(xs, dens)
    return xs.map(x => {
      const norm = maxDensity ? (dens(x) / maxDensity) * 0.42 : 0
      return { group: g, x, y1: yPos[g] - norm, y2: yPos[g] + norm }
    })

Comparing groups: the numbers

{
  function summarise(vals) {
    if (!vals.length) return { n: 0, mean: "—", median: "—", min: "—", max: "—", sd: "—", skew: "—" }
    const sorted = vals.slice().sort((a,b) => a-b)
    const mu  = d3.mean(sorted)
    const med = d3.median(sorted)
    const sig = d3.deviation(sorted)
    return {
      n: sorted.length,
      mean: mu.toFixed(1),
      median: med.toFixed(1),
      min: d3.min(sorted),
      max: d3.max(sorted),
      sd: sig !== undefined ? sig.toFixed(1) : "—",
      skew: sig ? ((mu - med) / sig).toFixed(2) : "—",
    }
  }

Can we claim a difference is real?

We can see differences in the charts.

But is the class the population we care about?

  • If yes — we have all the data. No inference needed. The difference is the difference.
  • If no — we are treating the class as a sample from a larger group (all students? all adults?).

This is the inference question.

Any sample will show differences between groups — by chance alone.

How do we decide which differences to take seriously?

That requires thinking about sampling, variability, and probability.

Six steps of EDA

  1. Start with the variables that matter most
  2. Qualitative variables — list frequencies
  3. Quantitative variables — look at the histogram
  4. Check for extreme values. Decide what to do with them, deliberately
  5. Look at summary statistics — let them guide further questions
  6. Explore further if needed — by group, over time, or otherwise
